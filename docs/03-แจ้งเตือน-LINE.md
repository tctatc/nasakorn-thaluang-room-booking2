# แจ้งเตือนทาง LINE และเอกสารแนบ

ทุกครั้งที่มีคนจองห้องสำเร็จ (ทั้งเจ้าหน้าที่ที่เข้าสู่ระบบและผู้จองทั่วไป) ระบบส่งการ์ดเข้ากลุ่ม LINE ที่เลือกไว้ การ์ดมี:

- วันที่ เวลาเริ่มและเวลาสิ้นสุด ชื่อผู้จอง ชื่อห้อง
- ชื่อไฟล์เอกสารแนบ และปุ่ม **เปิดเอกสารแนบ** (ถ้ามีไฟล์)
- ปุ่ม **ดูคำขอรออนุมัติ**

การ์ดไม่มีเบอร์โทรของผู้จอง เพราะข้อความในกลุ่ม LINE ถูกส่งต่อได้ง่าย

> ใช้ **LINE Messaging API** ผ่านบัญชี LINE Official Account (LINE Notify ปิดบริการไปแล้วตั้งแต่ปี 2025)
> ระบบยังทำงานได้ตามปกติแม้ไม่ได้ตั้งค่า LINE แค่ไม่มีการแจ้งเตือน

---

## ขั้นที่ 0: อัปเดตโค้ด Apps Script (ทำครั้งเดียวหลังได้โค้ดรุ่นนี้)

รุ่นนี้เพิ่มไฟล์ `45_Attachments.gs` และ `47_Line.gs` เพิ่มสิทธิ์ Google Drive และเพิ่มคอลัมน์เอกสารแนบ 4 คอลัมน์ในชีต Bookings

1. `npm run build:domain` แล้ว `clasp push` (หรือคัดลอกไฟล์ทั้งหมดในโฟลเดอร์ `apps-script/` ไปวาง รวม `appsscript.json`)
2. ใน Apps Script Editor เลือกฟังก์ชัน `setupSystem` แล้วกด **Run** หนึ่งครั้ง
   - Google จะขอสิทธิ์ใหม่ ("ดู แก้ไข สร้าง และลบไฟล์ Google ไดรฟ์ที่แอปนี้สร้าง") กดอนุญาต
     สิทธิ์นี้แตะได้เฉพาะไฟล์ที่ระบบสร้างเอง ไม่เห็นไฟล์อื่นใน Drive
   - ระบบจะเพิ่มคอลัมน์ที่ขาดต่อท้ายชีต (ข้อมูลเดิมไม่ขยับ) และสร้างโฟลเดอร์
     `ระบบจองห้องประชุม - เอกสารแนบ (ห้ามแชร์โฟลเดอร์นี้)`
3. **Deploy > Manage deployments > แก้ไข (ดินสอ) > Version: New version > Deploy**
   URL ของ Web app เท่าเดิม ไม่ต้องแก้หน้าเว็บ

> ถ้าข้ามข้อ 2 การจองจะขึ้นข้อความว่า "ชีต Bookings ขาดคอลัมน์ ... รัน migrateSheets()"

---

## ขั้นที่ 1: สร้าง LINE Official Account และ Messaging API channel

1. เข้า https://manager.line.biz ด้วยบัญชี LINE ของผู้ดูแล แล้วสร้างบัญชี LINE OA (เช่น "จองห้องประชุม วท.ท่าหลวงฯ")
2. ในหน้าบัญชี OA: **Settings > Messaging API > Enable Messaging API** แล้วเลือกหรือสร้าง Provider
3. ในหน้าเดียวกันของ OA Manager: **Settings > Account settings** เปิด **Allow bot to join group chats**
   ไม่เปิดข้อนี้ เชิญบอทเข้ากลุ่มไม่ได้
4. เข้า https://developers.line.biz/console เลือก channel ที่เพิ่งสร้าง แล้วเปิดแท็บ **Messaging API**
   - เลื่อนลงล่างสุด ตรง **Channel access token (long-lived)** กด **Issue** แล้วคัดลอกค่าไว้
   - ตรง **Webhook URL** วาง URL ของ Apps Script (ที่ลงท้ายด้วย `/exec`) แล้วกด **Update**
     จากนั้นเปิด **Use webhook**
     (ถ้ากดปุ่ม Verify แล้วขึ้น error ไม่ต้องกังวล Apps Script ตอบแบบ redirect ทำให้ LINE แจ้งว่า verify ไม่ผ่าน แต่ข้อความยังส่งมาถึงระบบได้ตามปกติ ให้ลองต่อในขั้นที่ 3)

## ขั้นที่ 2: ใส่โทเคนใน Apps Script

Apps Script Editor > **Project Settings** (เฟือง) > **Script Properties** > **Add script property**

| Property | Value |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | โทเคนที่คัดลอกมาจากขั้นที่ 1 |

โทเคนเก็บอยู่ที่นี่ที่เดียว ไม่อยู่ในโค้ดหรือในชีต และไม่มีคำสั่งไหนส่งโทเคนกลับไปที่หน้าเว็บ
**ห้ามวางโทเคนในแชต อีเมล หรือ GitHub** ถ้าหลุดให้กด Reissue ใน LINE Developers แล้วใส่ค่าใหม่แทน

## ขั้นที่ 3: เลือกกลุ่มที่จะรับแจ้งเตือน (ทำในหน้าเว็บ)

1. สร้างกลุ่ม LINE ของผู้อนุมัติ (หรือใช้กลุ่มที่มีอยู่) แล้วเชิญบัญชี LINE OA เข้ากลุ่ม
2. เข้าสู่ระบบด้วยบัญชีผู้ดูแล ไปที่ **ตั้งค่า > แจ้งเตือน LINE**
3. กด **รับรหัสกลุ่ม (เปิด 10 นาที)** แล้วพิมพ์อะไรก็ได้ในกลุ่ม LINE บอทจะตอบว่าเห็นกลุ่มแล้ว
4. กลับมาที่หน้าเว็บ กด **ดูรหัสล่าสุด** แล้วกด **เลือก** ที่กลุ่มนั้น
5. กด **ส่งข้อความทดสอบ** แล้วดูว่าการ์ดขึ้นในกลุ่มหรือไม่

ส่งหาตัวเองแทนกลุ่มก็ได้: เปิด "มีรหัสอยู่แล้ว" แล้ววาง **Your user ID** (ขึ้นต้นด้วย U) จากแท็บ Basic settings ใน LINE Developers
(ต้องเพิ่ม LINE OA เป็นเพื่อนก่อน) เลือกผู้รับได้สูงสุด 5 ราย

## เอกสารแนบ: ใครเปิดได้บ้าง

| ผู้เปิด | เปิดได้ไหม |
|---|---|
| ผู้ดูแลระบบ และผู้ลงนามทั้ง 3 ขั้น | ได้ ทุกคำขอ |
| ผู้จองที่เข้าสู่ระบบ | ได้ เฉพาะคำขอของตัวเอง |
| ผู้จองทั่วไป | ได้ เฉพาะคำขอที่ถือรหัสติดตาม (หน้า "ติดตามสถานะ") |
| บัญชีอื่น (เช่น ครูที่ไม่เกี่ยวข้อง) | ไม่ได้ ขึ้นว่า "ไม่มีสิทธิ์เปิดเอกสารนี้" |
| คนที่ได้รับการ์ด LINE ต่อมาแต่ไม่มีบัญชี | ไม่ได้ ปุ่มพาไปหน้าเข้าสู่ระบบก่อน |

- ไฟล์อยู่ในโฟลเดอร์ Drive ส่วนตัวของผู้ติดตั้ง ไม่มีลิงก์แชร์ ไฟล์ออกจากระบบได้ทางเดียวคือผ่านคำสั่งที่ตรวจสิทธิ์ทุกครั้ง
- ทุกครั้งที่มีคนเปิดไฟล์หรือถูกปฏิเสธ ระบบบันทึกลงชีต `AuditLogs` (`attachment.open`, `attachment.denied`)
- **ห้ามแชร์โฟลเดอร์เอกสารแนบใน Drive** ถ้าแชร์ จะข้ามการตรวจสิทธิ์ทั้งหมด
- รับไฟล์ PDF, JPG, PNG, Word (.docx), Excel (.xlsx) ไม่เกิน 5 MB ต่อคำขอ ระบบตรวจชนิดจากเนื้อไฟล์จริง
  ไฟล์ .exe ที่เปลี่ยนชื่อเป็น .pdf จะถูกปฏิเสธ
- ในโหมดทดลองบนเบราว์เซอร์ (ยังไม่ต่อ Apps Script) ไฟล์เก็บในเครื่องที่จองเท่านั้น ไม่เกิน 1 MB และส่ง LINE ไม่ได้

## ถ้าการแจ้งเตือนไม่มา

| อาการ | ตรวจที่ |
|---|---|
| หน้า "แจ้งเตือน LINE" ขั้นที่ 1 ยังไม่ติ๊ก | ชื่อ Script Property ต้องเป็น `LINE_CHANNEL_ACCESS_TOKEN` ตรงตัว |
| กด "รับรหัสกลุ่ม" แล้วพิมพ์ในกลุ่ม บอทไม่ตอบ | Webhook URL ใน LINE Developers ต้องเป็น URL `/exec` ล่าสุด และเปิด Use webhook ไว้ |
| ส่งทดสอบแล้วขึ้น "ไม่สำเร็จ (รหัส 401)" | โทเคนผิดหรือถูก Reissue ไปแล้ว ใส่ค่าใหม่ |
| "ไม่สำเร็จ (รหัส 400/403)" | บอทถูกเตะออกจากกลุ่ม หรือผู้ใช้บล็อก LINE OA |
| "ไม่สำเร็จ (รหัส 429)" | ส่งเกินโควตาข้อความฟรีของเดือนนี้ ดูโควตาใน LINE OA Manager > Insight / Usage |

การส่งที่ล้มเหลวไม่ทำให้การจองล้มเหลว การจองบันทึกแล้วเสมอ และมีบันทึก `line.fail` ในชีต `AuditLogs`

> โควตาข้อความฟรีของ LINE OA และวิธีนับข้อความที่ส่งเข้ากลุ่มเปลี่ยนได้ตามนโยบายของ LINE
> ตรวจตัวเลขล่าสุดใน LINE OA Manager ก่อนใช้งานจริง โดยเฉพาะถ้ากลุ่มมีสมาชิกมาก
